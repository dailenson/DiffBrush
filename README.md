## Introduction
### Purpose of this fork
This fork intends to apply and possibly extend DiffBrush to support German.

### Training Dataset
Sources for training dataset:
- Main: [ScaDS.AI German Line- and Word-Level Handwriting Dataset](https://zenodo.org/records/18301532)
- Style diversity boost: [Fachhochschuel Südwestfalen: German Handwriting](https://huggingface.co/datasets/fhswf/german_handwriting)
