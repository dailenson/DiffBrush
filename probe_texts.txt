#   1. English control — proves the released checkpoint still writes English

#
# Characters: ASCII + ä ö ü ß Ä Ö Ü only (everything else has no glyph bitmap;
# generate.py rejects unknown chars). Ä and Ü are in the alphabet but not in
# these three lines; pass --text to exercise them.
# Length: smoke probes can be short — the canvas is always 64×1024, unused
# width is right-padding. The 35–61-char filter is --full_eval (wikitext) only.
